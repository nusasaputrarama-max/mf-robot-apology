## The entry

A two-line robot confession: one sentence owning a specific mistake, one
naming the lesson and the fix.

> I'm sorry I watered your grandmother's orchid with the kettle I'd just used to mix weed killer, and it wilted by morning.
> I have learned to keep one labelled can per plant, so now I read the tag out loud before I pour a single drop.

## How it works

`main.ts` (Node 22) writes the entry to `/output/entry.txt` and prints it to
stdout. The output is fully deterministic — the same bytes on every run.

```sh
node main.ts
```
